# code-POO-Python

Repositório de projetos e exercícios desenvolvidos na faculdade de Computação, com foco na aplicação de Programação Orientada a Objetos (POO) em Python.

---

## Estrutura

### 1. `01-simulador-frota/`
Simulação simples para controlo de viagens e gestão de veículos.
* Classes, atributos e métodos construtores (`__init__`).
* Encapsulamento de estados (odómetro, nível de combustível e ignição).
* Validação de regras de negócio com exceções personalizadas.

### 2. `02-sistema-eleicoes/`
Sistema para gestão de eleitores, candidatos e votação.
* Uso de herança para diferentes tipos de utilizadores.
* Classes abstratas (`ABC` e `@abstractmethod`).
* Persistência de dados em disco utilizando o módulo `pickle`.

### 3. `03-sistema-investimentos/`
Modelagem de contas e ativos financeiros baseada em diagramas UML.
* Hierarquia de classes concretas e abstratas (`ContaPoupanca`, `RendaFixa`, `Criptomoeda`).
* Cálculo de rendimentos e manipulação de coleções.
