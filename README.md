# code-POO-Python

Repositório de projetos e exercícios desenvolvidos na faculdade de Computação, com foco na aplicação de Programação Orientada a Objetos (POO) em Python.

---

## Estrutura

### 1. `01-simulador-frota/`
Simulação simples para controlo de viagens e gestão de veículos[cite: 11, 12].
* Classes, atributos e métodos construtores (`__init__`)[cite: 12].
* Encapsulamento de estados (odómetro, nível de combustível e ignição)[cite: 12].
* Validação de regras de negócio com exceções personalizadas[cite: 12].

### 2. `02-sistema-eleicoes/`
Sistema para gestão de eleitores, candidatos e votação[cite: 8, 10].
* Uso de herança para diferentes tipos de utilizadores[cite: 8, 10].
* Classes abstratas (`ABC` e `@abstractmethod`)[cite: 8].
* Persistência de dados em disco utilizando o módulo `pickle`[cite: 10].

### 3. `03-sistema-investimentos/`
Modelagem de contas e ativos financeiros baseada em diagramas UML[cite: 8].
* Hierarquia de classes concretas e abstratas (`ContaPoupanca`, `RendaFixa`, `Criptomoeda`)[cite: 8].
* Cálculo de rendimentos e manipulação de coleções[cite: 8].
